# Journey 微信小程序重构进度

## 当前阶段
- 已完成 Taro + React 小程序骨架。
- 已保持一级结构为：首页、里程、我的。
- 已保持 Food / Activity 为二级页面。
- 主链路仍为：微信登录 -> 邀请码准入 -> 记录饮食/活动 -> 首页联动 -> 里程多天回看。

## 本轮完成
- 后端 `/auth/wechat-login` 已从 mock openid 切为真实微信 `code2Session` 调用。
- 新增微信环境变量读取：`WECHAT_APP_ID`、`WECHAT_APP_SECRET`。
- 前端登录仍使用 `Taro.login()` 获取 `code` 后调用后端。
- 前端会缓存业务 `token` 和 `user`，不缓存 `session_key`。
- 邀请码逻辑保持不变，未激活用户仍会被业务接口拦截。
- Taro 依赖已真正安装完成。
- `npm run build:weapp` 已成功通过，`dist/` 已生成小程序产物。
- 已补充联调文档和环境变量模板。
