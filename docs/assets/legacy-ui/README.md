# 旧版运行截图目录

该目录保存基线 commit 对应的微信开发者工具运行截图。采集环境、虚拟演示数据、
AI 候选临时响应和固定采集规范见
[`../../product/LEGACY_UI_REFERENCE.md`](../../product/LEGACY_UI_REFERENCE.md)。

禁止放入 AI 生成图、手工重绘页面或包含真实账号/个人健康数据的截图，并把它们标记为旧版运行证据。

当前共 14 张：

1. 登录与邀请码；其中 `01-auth-default.png` 是用户实际操作得到的登录失败截图。
2. 首页空态、有数据态和 AI 回退态。
3. Journey 空态和有数据态。
4. 我的默认资料态和完整资料态。
5. 饮食精确记录与 AI 候选态。
6. 活动精确记录与 AI 候选态。
7. 后端不可达错误态。

注意：登录后的页面通过开发者工具本地虚拟会话进入，只用于保存旧 UI 和状态证据；
旧版真实微信登录当前无法连接 `127.0.0.1:8000`，没有通过端到端验证。
