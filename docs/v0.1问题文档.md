## V01-01：旧微信小程序无法支撑跨平台交付

**遇到了什么问题**

- 原产品绑定微信小程序技术栈，iOS、Android、Web 无法共享统一交付路径。
- 旧端业务逻辑、数据存储与界面耦合，后续 Agent、RAG 和自动化测试难以复用。

**使用了什么技术解决**

- 客户端迁移为 Expo/React Native，固定首页、Journey、我的三个一级入口。
- 后端迁移为 FastAPI 模块化单体、PostgreSQL 和 Alembic，跨端共享 `/api/v1` 契约。
- 使用 npm workspace 管理客户端契约与设计 Token，微信/Taro 客户端按清单退役。

**完成度：100%**

- v0.1 已形成 iOS、Android、Web 构建路径和共享后端；旧微信端不再是当前运行入口。
- 边界：三端构建通过不等于 App Store、Google Play 或公网生产发布。

## V01-02：Agent 可能在用户不知情时写入健康记录

**遇到了什么问题**

- 自然语言可能同时包含饮食、运动和查询，直接执行会产生错误记录或重复写入风险。
- 模型输出不稳定，单靠 Prompt 无法保证所有写操作都经过用户确认。

**使用了什么技术解决**

- 建立 Orchestrator 与职责受限 Specialist，使用类型化工具白名单、结构化计划和 Policy Guard。
- 所有写操作先生成候选，通过 Confirmation Gate 后才写库；增加幂等键、checkpoint、恢复与有限重规划。
- 使用 Mock 确定性测试、Requests 网络黑盒和真实 Provider 小样本门禁验证主链路。

**完成度：100%**

- v0.1 的饮食、运动和体重 Agent 写入均经过确认门，恢复流程保持幂等。
- 边界：完成的是有界工作流，不是无限自治、多 Agent 群聊或医疗决策系统。

## V01-03：健康知识回答缺少可量化的依据门禁

**遇到了什么问题**

- 生成式回答可能脱离受控知识或给出无法核对的结论。
- 只看少量演示问题无法判断检索、引用、拒答和真实生成质量。

**使用了什么技术解决**

- 建立版本化受控知识源、RAG 检索、引用结构和 `insufficient_context` 拒答。
- 建立 60 题固定 RAG Eval，分别度量 Recall、MRR、Groundedness、Relevance、Citation
  Correctness 和 Abstention。

**完成度：90%**

- v0.1 历史结果为 Recall@3/5 1.0、MRR 0.9625、Groundedness/Relevance 0.9625、Abstention
  1.0；Citation Correctness 0.9083。
- 空引用漏洞及更严格的最终校验转入 v0.2 `FIX-02`，因此该问题在 v0.1 不标记 100%。

## V01-04：离线记录、跨设备同步和冲突可能造成数据丢失

**遇到了什么问题**

- 移动端断网或切后台时，新增、修改和删除可能无法立即到达服务端。
- 本地旧版本覆盖服务端新版本会造成静默数据丢失；退出后残留健康数据也有隐私风险。

**使用了什么技术解决**

- 原生端使用 SecureStore 密钥和 AES-256-GCM 保存按账户隔离的本地副本。
- 使用离线 Outbox、自动重试、服务端 version/`If-Match-Version` 和字段级冲突选择。
- 退出账号时清理密钥、缓存、Outbox 和本地健康数据；Web 只保留进程内副本。

**完成度：100%（v0.1 验收范围）**

- 离线 CRUD、恢复同步、冲突选择和退出清理均形成实现与测试基线。
- 边界：大规模故障注入、真实设备密钥取证和公开生产环境验证仍属于 v0.2 发布门禁。

## V01-05：食物图片模型无法达到正式产品质量

**遇到了什么问题**

- 单张图片缺乏可靠尺度，无法准确推断份量和热量。
- 真实 Qwen 密封评测中，Top-3 为 67.27%，中国家庭餐为 60%，未通过质量门禁。

**使用了什么技术解决**

- 使用授权密封集、零重叠校验、Schema 门禁、尺度参照实验和唯一一次真实评测控制数据泄漏。
- 将能力降级为 Development 实验性“识别候选 + 用户校正 + 确认保存”，Preview/Production 默认关闭。

**完成度：100%（风险关闭），模型能力未发布**

- v0.1 正确执行了 No-Go，没有把失败指标包装成正式能力。
- 这不代表图片识别质量已修好；重新启动必须使用新决策、新密封集和预注册评分规则。
